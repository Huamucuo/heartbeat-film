# v09 / 本轮取舍

保留 v08 完整源文件、4K 和 1080p 成片，v09 在独立目录内制作。片长仍为 340 秒，音乐与全片时间基准保留。

实际解码审看提出的三项优先问题：180–198 秒住宅只拉高盒子，缺少生活空间的变化；198–216 秒公交和列车共用轮廓、两个路轮，交通演进不能被可靠辨认；279–297 秒蛋糕整体压扁，消耗的意象不成立。

比较三种做法：物件的工程爆炸图可以丰富结构但过于商品化；纯地图图形可以统一轨迹但会重返线条重复；选择“生活空间逐渐替换”的小剧场，物件有自己的工业/建筑结构，保留共同地面和方向，以经过、遮挡、消耗来推进时间。

通勤先做可播放小样。轮圈由真正空心的车圈、辐条和轮毂组成；公交保留轮拱、风挡、双扇车门；列车改成驾驶室、钢轮转向架、滑门、车底设备及车厢连接。后景从街巷到站台，地面从标线到钢轨，同向移动有前后层速差。观众先认出车辆，再看到空间的速度越来越快，最后感到路线仍相似。仍采用深蓝、青灰、暖象牙、低饱和赭红，不换为塑料质感。
