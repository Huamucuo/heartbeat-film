# v07 剪辑与继续编辑

| 时间 | 画面与叙事 |
|---|---|
| 0–7.5 秒 | 心跳与余波开始书写时间，波形本身运动 |
| 7.5–17.5 秒 | 126 份记录，10–16.5 秒日期与单日近景；DAY 每 0.625 秒加一 |
| 17.5–27.5 秒 | 记录进入实体城市，镜头从生长的房屋移向满屏建筑 |
| 27.5–37.5 秒 | 两个节律相互干涉，短暂同频 |
| 37.5–47.5 秒 | 三条不规则路线分别在 40.625、43.750、46.875 秒回同一原点 |
| 47.5–57.5 秒 | 走过的路线成为层叠历史空间，声音降低，画面仍流动 |
| 57.5–63.8 秒 | 共同信号分枝，九个具体生活事件按声音事件逐渐出现 |
| 63.8–73 秒 | 推近旧电话，拨盘到按键到触屏；后半段逐渐退回生活全貌 |
| 73–80 秒 | 孩子长大离开，餐桌空出一侧，生日和行李变化，人物老去；生活收成回忆的窗 |
| 80–90 秒 | 回忆远离，片名进入，最后一句落下时 ECG 仍在书写 |

几何由绝对时间决定，不能依赖上一帧。文字在曝光积累后绘制，避免多重字影。实体线和面共同按物体及表面排序；回忆窗与其内容作为整体处理遮挡。不要把 ECG 换回不含时间的固定曲线。

声画继续共用 600 个原创事件和 96 BPM 时钟。原有五分轨与 edition v04 保持不变。字体随包提供。验证与复建步骤见 README。
