## 1. 画面为什么改变

554–625 行中，雪花的对称操作、乘法表、钟面不是任意替换的漂亮图案。前一阶段提出的问题，决定后一阶段该出现什么；对象的身份和位置又让观众记得它从哪里来。1294–1398 行的 E8 按层建立、终章收回雪花，也有这种递进和回收。

《心跳》本轮的对应决定：每份心跳记录长成一栋房子；原点出发的信号分枝为联系、工作、住处、通勤、相伴、家人、身体、生日、远行；它们保留具体形状进入回忆中的窗，最后逐渐远离。首轮把生活轮廓全部扭成光线漩涡，虽然连续，却失去了可理解的意象，因此撤回该设计。

## 2. 满屏空间与单个物件

721–826 行的魔方由 27 个小块的实体面、贴片、法向明暗、背面剔除与深度排序组成；转层动作有绝对时间定义。画面中有真正的遮挡、色块面积和厚度，不是所有边都透出来的线框。108–251 行的背景着色器、833–878 行的花纹与晶体、937–978 行的纸与烛火，说明不同概念需要不同表面。

《心跳》独立写了 `Solid` 面片渲染器。城市用 126 栋不透明楼体、屋顶与有明暗的窗；电话有外壳、拨盘孔、听筒、线缆、按键、屏幕与侧键；桌面、信封和书保留木、纸与哑光颜色。首轮查出地面盖住楼房、机身盖住键盘，修正为物体分组、表面分层和背面剔除。没有重新使用用户否定的镜面金属与棚拍反射。

## 3. 构图有尺度等级

参考会在大数字、主要物件、满屏图案、人物留下的纸面之间改变面积和距离。图形密度并非一直堆高。魔方镜头给实体、巨大数字与说明各自的位置；纸面场景又让书写成为主体。

《心跳》现在经历：细小记录阵列 → 日期近景 → 满屏城市 → 两种节律 → 三次路径回归 → 生活全貌 → 一部旧电话的近景 → 回到已经改变的生活全貌 → 回忆窗口退场。用镜头距离和实体面积制造变化。城市不是额外装饰背景，而是日子累积出的生活环境。

## 4. 数字必须说明事情

780–787 行 `rollNumber` 让位数依次锁定；814–820 行的大数与 170 px 的“20”分别表达组合数量与解题上限；862 行的 190 px“230”也对应明确概念。这些数字具有内容身份，不能抽掉意义只留下计数器外观。

《心跳》只保留有解释的数字。DAY 从既有第 054 日按 96 BPM 每拍增加一天，126 px 数字使用固定宽度位置，只有发生变化的位数在 0.18 秒内上下交接；字样“已经过去的日子 / 再也不能重来”说明它的含义。回归数字表示已真正到达原点的次数。去掉画内装饰性章节编号和物体旁的编号单字。

## 5. 文字也有主次与动作

59–100 行分开中文宋体、英文衬线、斜体、数学与等宽字；380–401 行 `titleWord` 逐字出场并变化尺寸；1499–1522 行把章名、英文副题、底部字幕分层，字幕下有渐隐暗带。不是把所有文字放进同一种小号标签。

《心跳》用 Noto Serif SC 的正式字重：片名 174 px / 700，章名 42 px / 700，叙事字幕 33 px / 400，英文副题 12 px，DAY 数字 126 px。中文有字距、章名有轻微入场位移，字幕始终有对比度支撑；日期背后增加柔和暗场，使它从记录阵列中站出来。结尾保留温白片名和克制的金色副题，符合本片的悲观语气。字体随工程附带官方 OFL 许可。

## 6. 连续运动和音乐各自承担什么

参考用节拍命中关键事件，又让镜头、内部形变和局部细节保持连续。取法这一分工：《心跳》的 600 项原创音乐事件继续提供 96 BPM 时钟；日期每拍推进，九次分枝对应九个音，联系与消失沿用事件时刻。电话演化、车轮、蒸汽、翻页、灯光、人物动作和窗格漂移由绝对时间控制。悲观不等于让画面停住。

## 7. 检查方法与边界

每轮执行“回读相关源码 → 实现 → 连续样帧 → 查出问题 → 修正”。图形状态测试、任意跳转一致性、转场边界、排除背景后的主体差分、实际 MP4 解码、播放器与归档分别核验。数值通过不等于达到参考的艺术水平。
