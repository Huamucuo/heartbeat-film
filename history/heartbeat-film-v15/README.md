# 心跳 v15

本轮仅修改迷宫的拉远视野、转场心电和配乐节奏。

- 66 秒起持续扩大视野，迷宫始终超出画面；88.4 秒开始模糊，92.3 秒完全进入黑屏。
- 93.3–95.5 秒在黑屏中仅扫过一次红色实测心电图，与 94.25 秒一次心搏同步。波形使用 MIT-BIH 100 的真实 MLII 数据，保留原采样时钟；不是弧状装饰曲线。
- 95.8–98 秒再留黑屏和静音；98–99.2 秒生活画面进入。
- 配乐从原来的 132–248 BPM 降为 96–116 BPM，减少后段音符和打击密度。88.4–92.2 秒音乐和混响一起渐退。

总长 161.7 秒，约 2 分 42 秒。其余生活模块、代码心脏与最后监护长鸣保留。

成片：output/heartbeat-v15-1080p.mp4、output/heartbeat-v15-4k.mp4。可打开 index.html 播放。v14 完整保留。按要求不审片、不试听，由用户验收。

制作：node tools/export-score-v15.mjs；python audio/synthesize.py；node tools/master-audio.mjs；node tools/export-v15.mjs。双时间映射仍在 src/pacing.mjs；旧版动作时钟仍为原196秒时间，勿直接混用。只重新渲染61.5–100秒，其余从原生4K素材拼接。
素材来源与许可见 docs/credits.md。声音和实测心电数据属于不同来源；心搏声是合成音效。
