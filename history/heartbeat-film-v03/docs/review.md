# 第三版独立复核与处理

复核由独立上下文完成，只读源码、现有截图和报告；没有启动 GPU，没有代称完整试听。没有 Critical 发现。

重要发现：16 点稀疏景深造成晶体和塔边缘的离散重影，中心深度不足以防止前景污染背景。已回读参考晶体层级处理，将半径收至原值约 28%，使用 32 点深度约束并降低主体失焦。已实看 31、62、78.5 秒修正帧，前景轮廓和晶体高光不再出现旧版明显的分身。

尾迹原先在 54 / 58 秒硬切。因该段极安静、光点是核心事件，将此项从 Minor 提升到重要的视觉连续性修正；先通过测试复现 54 秒 0→1 的跳变，再与光点共用淡入淡出包络，完整渲染检查随后重跑。

一个暂不影响成片的统计项：浏览器报告里的 drawCalls / triangles 仅是最后一个全屏 pass，不能代表整帧场景复杂度。本次不依靠该数字评估性能，使用真实 4K 导出耗时和错误记录。该调试统计的命名改进留待后续。

边界微量测试只证明几何与相机位置连续，不证明曝光、材质或整个 2.2–3.5 秒形变观感。最终验收另外使用实际视频解码的相邻帧与交接过程采样；对此不作超出检查范围的声明。

审美观察：轮廓差异已超过单纯变换圆环；暖白陶瓷、满幅织带、双塔、无穷形体、空白、瓣片和晶体网络可区分。偏悲观主旨已进入分离、循环、连接释放和末环缺口。花瓣段的短暂明亮作为后续落空的铺垫保留；代价是该局部单独观看仍可能被读作希望。

复核没有判断：完整音乐的主观品质、全程观看情绪、所有透明交叉角度、持续 4K 编码稳定性及最终包。这些分别由后续实际导出与检查补充；没有工具能以通过检查来保证“极致美观”或与参考作品艺术质量等同。
