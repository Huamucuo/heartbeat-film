# 《心跳》：活着的意义

主旨：生命持续发生，但持续本身并不自动提供意义。人试图用忙碌、靠近、秩序与连接回答“为什么活着”，答案始终没有抵达。

基调偏悲观、克制，保留美与困顿的张力。金属和陶瓷依然美丽；压抑来自无法完成的关系和不断回返的运动，而非全片压暗或不断叠加痛苦意象。

音乐：96 BPM 的网格，听感围绕半速的心跳。毡音键盘下行，A 小调及悬置和弦，后段降低高音密度；结尾不转大调，不给出胜利式终止。声音与画面使用同一事件表，连接的建立和消失都可追到具体音符。

镜头与颜色：保留上一版获认可的铜金、青绿和墨色；暖白段为情绪提供反差。真实厚度、材料反射、构件之间的遮挡和近远变化承担复杂度；避免把多放粒子视作丰富。
