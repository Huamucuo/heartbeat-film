# 《心跳》v04 / 活着的意义

90 秒原创抽象音乐短片。使用 v03 已创作的偏悲观音乐与相同事件表，重做图形体系。不是为数学教学编造公式，而是借鉴参考作品将关系可视化的能力。

时间线：发生 0–7.5；重复 7.5–17.5；奔赴 17.5–27.5；彼此 27.5–37.5；循环 37.5–47.5；空白 47.5–57.5；追问 57.5–67.5；回声 67.5–80；心跳 80–90。

以一个珊瑚红脉冲为视线锚点。记录采用平面纹理和细线，路线来自记录的位移；两种节律用两组波面呈现；联系成为节点之间逐条建立的连线，结尾随音乐事件逐条消失。色面、网格与前后遮挡提供空间，不使用亮面实体管。

字幕表达疑问与事实，不将悲观包装成励志反转。片尾：答案没有到来。心跳仍在继续。

实现：独立 Canvas 2D 程序绘制和三维坐标投影；基于绝对时间的可重现画面；原生分辨率输出，局部光晕与低强度场景扩散、微弱颗粒；章节标题和字幕后置，场景内部标签仍参加曝光采样。原有合成音乐与 48 kHz 音频；FFmpeg 合成 H.264 / AAC，先查样帧与交接再导出。
