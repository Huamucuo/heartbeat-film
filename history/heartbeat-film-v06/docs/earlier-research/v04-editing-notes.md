# 可继续剪辑的材料

## 时间线

| 时间 | 视觉变化 | 音乐和情绪 |
|---|---|---|
| 0–7.5 | 一条心电轨迹；一次心跳成为向外扩散的记录 | 双击心跳与少量键音，起点没有选择 |
| 7.5–17.5 | 108 个固定编号的记录展开；DAY 054 进入前景 | 低音与断续拨弦开始构成日常 |
| 17.5–27.5 | 同一批记录移入闭合路线；光点奔赴 | 节拍增加，但路线没有出口 |
| 27.5–37.5 | 红、青两种节律相遇，薄波面形成干涉 | 第二种脉动保持相位差；“短暂同频”不等于融合 |
| 37.5–47.5 | 日常的矩形形状回到迷宫式重复 | 循环与节拍继续，次数和路线共用 5 秒周期 |
| 47.5–57.5 | 结构退去，空白出现；一个光点跨越空间 | 主心跳与另一种脉动停止，55 秒出发、57.5 秒抵达 |
| 57.5–67.5 | 落点保留为种子；九个节点逐次生长 | 每次生长对应 bloom 音符，DAY 054 再出现 |
| 67.5–80 | 18 项联系渐次建立，又逐条撤回 | 连接与断开的时刻各有事件和短促音色 |
| 80–90 | 大部分联系已散去；旧记录成为背景，心电未闭合 | 低动态回落，悬置音程未解决，留下题目 |

## 音频

五个 stem 文件都从 0 秒开始，长度 90 秒。导入音频工作站后将起点对齐即可。

- `stem-pulse.wav`：两组脉动、到达音与低音。
- `stem-melody.wav`：毡感键音、拨弦与连接音。
- `stem-harmony.wav`：持续和声。
- `stem-percussion.wav`：轻节拍与刷声。
- `stem-detail.wav`：旅程、生长、断开、铃声和过门。

这些是预母带总线，相加近似重建 `source-mix.wav`，并不直接等于压限和响度处理后的 `master.wav`。微小差异来自去直流和 16-bit 量化。最终片内 AAC 的响度应读取 `output/verification/delivery.json`，不要用预母带数值代替。

`src/score.mjs` 是修改音乐事件的入口；导出后 `audio/score.json` 可供合成器读取。改音乐时需要重新生成声音；改画面时可继续使用母带。`docs/dialogue.srt` 是剪辑参考，已有 MP4 的字幕已经烧录，叠加 SRT 会出现重复文字。

## 参考继承和仍有的边界

主参考的可借鉴之处是图形关系随概念增加、共享对象跨镜头改变表示，以及主体和重复结构之间的观看距离变化。本片独立使用心电、日常记录、循环与关系；没有搬用其数学演示或音乐。

DAY 054 是跨章回收的记忆母题，在中段并非每一帧都持续显示。记录墙到路线使用同一批索引；其他章节采用共享造型和时间重叠交接，不能将全片宣称为一个毫无切换的三维连续镜头。画面采用投影与透明结构，也不声称具有完整三维光照、深度缓冲或真实景深。

最终检查分为源代码与静帧复查、输出媒体解码与文件校验、播放器操作。没有把自动检查等同于完整主观观影和听音验收；用户对节奏和审美的反馈仍是下一轮创作依据。
