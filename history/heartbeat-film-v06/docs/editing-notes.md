# v06 剪辑与继续编辑

- 0–7.5 秒：一次心跳开始写下时间，信号和余波持续运动。
- 7.5–17.5 秒：126 份记录铺开；10–16.5 秒放大一日，DAY 每 0.625 秒递增，波形独立滚动。
- 17.5–27.5 秒：记录的行列沉积成有前后层次的薄色地层，信号在层间行进。
- 27.5–37.5 秒：两种节律产生起伏、干涉、短暂同频。
- 37.5–47.5 秒：三条不同的不规则路线，40.625、43.750、46.875 秒返回同一原点后增加计数。
- 47.5–57.5 秒：真实走过的路线抬升成层叠空间。配乐降低，画面仍有流动和镜头纵深。
- 57.5–67.5 秒：一条共同信号分枝；九种生命曲线随原作音乐出生事件折叠生长，再连续展开。
- 67.5–80 秒：117 条主体纤维形成大幅织物、卷曲成立体结构；联系按原乐谱的 connection/release 事件建立和离开。
- 80–90 秒：共同结构逐束远去，边缘仍有流动残影，末尾 ECG 持续书写。

所有状态来自绝对时间，可直接跳转。不要把波形重新换成固定 heartWave(u)；主路径、记忆副本和背景的运动应分别检查。主体运动测试不绘制背景星点、颗粒或字幕。两次曝光样本用于成片，文字后置。

原配乐、600 个事件、五个分轨沿用，不因视觉版号而改写音乐 edition。字体和运行环境限制见 README。
