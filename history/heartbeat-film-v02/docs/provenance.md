## 本片自己的材料

图形、镜头、文字排布和音乐事件为本工程新编写；声音由 NumPy 加法合成与确定性噪声产生，无外部音乐采样。仅使用系统字体绘制中文和英文，未复制或分发系统字体文件。成片已固化文字外观。

五个 `stem-*.wav` 为同长 90 秒、48 kHz、16 bit 立体声：脉动 / 旋律 / 和声 / 打击 / 细节。它们包含各自空间处理与总体进出包络，尚未经过最终总线响度处理；相加时需要保留余量。`master.wav` 为 24 bit 最终混音，MP3 与 MP4 使用该混音导出。

依赖 Playwright、浏览器和 FFmpeg 仅用于本机渲染，不把它们的二进制程序包含在本工程包。重建时请遵守各自许可证。工程包不包含参考快照、旧版样片、测试用旧材质片段或其他项目文件。
