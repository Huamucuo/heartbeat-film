# 心跳原创抽象音乐短片设计稿

《心跳》讲述一次脉动如何得到回应。一点微光先在空白中留下痕迹，痕迹长成能够传递振动的薄膜；两个节律相遇、错开，经历一次等待后，回声沿旧路径返回，最终形成多个独立节点的共同呼吸。

用户已选定原创抽象音乐短片方向。本稿把约 90 秒的构思落实为 90 秒、18 个镜头段的设计提案，包含画面、音乐、转场和制作验收要求。音乐、画面及渲染程序尚未制作；以下数值是制作目标，不能视作已测结果。

## 创意方向与取舍

| 方向 | 能形成的作品 | 主要代价 | 选择 |
| --- | --- | --- | --- |
| 脉动留下痕迹并传播 | 用同一批几何元素讲清发出、错拍、等待和回应，适合连续变形与原创器乐 | 薄膜质感、空间遮挡及波前传递需要重点打磨 | 本稿采用 |
| 城市与人的共同心跳 | 窗灯、道路、呼吸和人群之间建立联想 | 需要大量环境与人物素材，会分散抽象图形主线 | 留作另一部作品 |
| 纯文字节奏片 | 字形、字距和版面直接成为节奏 | 当前没有歌词，文字难以支撑完整情绪递进 | 只吸收片尾排字方法 |

核心叙事规则：每次形变都留下下一段继续使用的材料。观众始终能找到开场的珊瑚色脉动源，并认出回应走过的路径。

视觉主角是一枚不规则、略有缺口的珊瑚色微核。缺口方向和表面纹理保持不变，缩远后仍由同一枚小高光标识身份。另一端的青色微核具有不同节律。最终两者进入同一呼吸周期，仍保留各自较细的脉动差异。

## 画幅和美术

主版本为 1920×1080、16:9、30 fps、90 秒，共 2700 帧。以清晰的 1080p 样片判断质感；4K 和竖屏不属于本稿必需交付。

空间像一张悬在暗处、受到掠射光照亮的薄膜。近处能看见细微纤维，中景有明确的弧线和波前，远处由低对比表面延伸出纵深。光源方向大体稳定，运动由材料形变与相机位置解释。

| 角色 | 色值 | 画面用途 |
| --- | --- | --- |
| 暗底 | #0B1018 | 大部分负空间，保留可见暗部层次 |
| 主脉动 | #F16A5B | 开场微核及其传出的波前 |
| 回应 | #66C7C0 | 另一端微核、回流与后半段关系 |
| 材料亮部 | #E7DAC5 | 薄膜纤维、交汇处和片尾文字 |

前三段由珊瑚色占主导；错拍段降低背景饱和度；等待段留下很少的色彩；回应段让青色沿既有路径进入。高潮扩大可见空间和受光面积，保持两种主体色的区别。

1080p 下关键曲线初始目标为 2–4 px，微细纤维更暗。辉光只托住亮部边缘，主体关闭辉光后也应具有清晰轮廓。每一构图只安排一个首要观看点，前景折边偶尔遮住中景，确认深度关系。

全片只出现片尾标题“心跳”和小字“HEARTBEAT”。中文采用有开口和呼吸感的中等字重，英文保持疏朗；具体字体在制作时以可本地打包的授权字体确定。字形由排版层绘制，不进入生成式纹理。

## 全片时间轴

音乐设为 96 BPM、4/4 拍。每拍 0.625 秒，每小节 2.5 秒，共 36 小节。下表小节从 1 开始计数，所有区间左闭右开。

| 时间 | 小节 | 段落 | 画面和叙事变化 | 声音与镜头 |
| --- | --- | --- | --- | --- |
| 0–10 秒 | 1–4 | 第一次脉动 | 微核在暗处收缩两次，局部纤维被照亮；随后运动并留下可追踪的弧线 | 干燥的低音双击，几乎无和声；微距缓慢拉开 |
| 10–22.5 秒 | 5–9 | 痕迹成为材料 | 弧线弯成开口环，缺口逐步闭合；纤维从边界铺入环内，出现薄膜 | 加入三音动机；相机从正视转向掠射角，显示厚薄 |
| 22.5–35 秒 | 10–14 | 脉动可以传播 | 一次收缩把波前推向远处；沿折痕传播的光依次显出空间，青色微核出现 | 短延迟与软质敲击加入；镜头跟随单个波前，给观众观察时间 |
| 35–47.5 秒 | 15–19 | 两种节律 | 两个微核各自发声，波前交错，有些区域相遇，有些擦肩而过 | 青色声部错开半拍；中近景交替，逐步增加节奏密度 |
| 47.5–57.5 秒 | 20–23 | 等待 | 受光面积收回，旧路径仍可见；预期的一次脉动缺席，远端先出现很弱的回应 | 逐层撤掉鼓和和声；55–56.875 秒不再触发双击，镜头停住 |
| 57.5–72.5 秒 | 24–29 | 回声返回 | 青色波前沿先前路径回到主微核，接触后逐次唤起另外七个节点，总计九个 | 57.5 秒落在强拍；主旋律与回应形成问答，低频重新进入 |
| 72.5–82.5 秒 | 30–33 | 共同呼吸 | 相机拉高，之前看到的局部连成同一张起伏表面；九个节点共享慢呼吸并保留细小相位差 | 最饱满的一段，空间和声像展开；主要镜头运动反而放慢 |
| 82.5–90 秒 | 34–36 | 回到近处 | 镜头回到开场微核，主形让出中央留白；标题显影，远处仍有回应 | 逐层撤掉配器；88.75 秒最后一组双击，尾音自然收至 90 秒 |

结尾的变化在于开场微核已处于可见的关系网中。最终留有微弱生命感，标题保持可读，不以模拟监护仪的平线收尾。

## 十八个镜头段

这些是导演与渲染的时间窗口，不要求十八次硬切。相邻镜头优先通过跟随、形变、遮挡和视点转移完成交接。

| ID | 时间 | 主体与构图 | 运动及交接 |
| --- | --- | --- | --- |
| S01 | 0–5 | 主微核特写，大面积暗底 | 两次轻收缩显示缺口和纤维；缓慢拉开 |
| S02 | 5–10 | 微核开始横向运动 | 尾迹由同一条曲线记录；末端运动延续到 S03 |
| S03 | 10–17.5 | 曲线弯成开口环 | 相机跟随曲线端点，尾迹实体感逐渐增强 |
| S04 | 17.5–22.5 | 环内形成半透明薄膜 | 边界点保留，纤维从边缘向内铺展；相机降低视角 |
| S05 | 22.5–30 | 一个波前穿过薄膜 | 主要跟随一个波峰，不同时点亮全部节点 |
| S06 | 30–35 | 远端青色微核露出 | 前景折边掠过，揭示远端；到边界时固定接收者屏幕位置 |
| S07 | 35–40 | 两个微核分居前后 | 半拍错位产生两个方向的波前 |
| S08 | 40–45 | 交汇处近景 | 相遇时局部增亮，错开时保留两条可分辨轨迹 |
| S09 | 45–47.5 | 刚建立的联系又错开 | 用一条折边移出观看点，引向主微核的孤立状态 |
| S10 | 47.5–52.5 | 表面变暗，路径仍在 | 退去外围运动，镜头回收至主微核 |
| S11 | 52.5–55 | 主微核中近景 | 最后一轮预期建立后，停住相机 |
| S12 | 55–57.5 | 暗部旧路径，远端轻亮 | 留出 1.875 秒无新双击区间；56.875 秒出现回应并开始回程 |
| S13 | 57.5–65 | 回声到达微核 | 57.5 秒到达点只触发一次局部形变；随后传播到已有表面 |
| S14 | 65–72.5 | 两个微核唤起其余七个节点 | 节点从波峰受光处显出，每次出现有因果来源 |
| S15 | 72.5–77.5 | 全景显出九节点与完整薄膜 | 抬高视点，共享慢呼吸；高潮以空间揭示成立 |
| S16 | 77.5–82.5 | 由全景回到主微核 | 近处折边压过远景，视觉尺度逐渐亲密 |
| S17 | 82.5–85 | 微核移至标题下方 | 曲线向两侧让出留白，标题按双击分两级出现 |
| S18 | 85–90 | 标题、主微核与远端回应 | 固定构图；88.75 秒双击后只保留尾音和细微余动 |

S01、S12、S18 是三个明确的停留点。S08 的局部密集变化用于制造错拍感；S15 不增加剪切速度，让空间揭示成为高潮。

## 连续性与空间契约

全片持有稳定的对象身份：pulse.origin、pulse.reply、trace.main、membrane.main 和七个后续节点。曲线主边界使用固定数量与顺序的采样点；表面的材质坐标在相机运动和形变时保持对应。

曲线成环时，端点先靠近，接缝再闭合，声音在接缝完成时给一个轻触音。薄膜从环的边界生长，不能在下一镜头突然替换为无关网格。节点由已有波峰唤起，不重新随机生成位置。

所有相机参数以全片时间求值。若拆成多个场景模块，各模块同时调用共享的主体状态函数；边界两侧必须匹配位置、尺度、透明度、颜色及屏幕速度。只做透明度交叉淡化不足以保证运动连续。

| 交接时间 | 必须继承的画面状态 | 制作目标 |
| --- | --- | --- |
| 10 秒 | 曲线端点及切向速度 | 两侧共用 traceTip(t)；边界参考端点为 (1260, 540)，切向向右 |
| 22.5 秒 | 同一环边界与内部纤维 | 参考投影中心 (960, 540)，外接椭圆半轴约 (300, 135)；通过同一相机矩阵计算 |
| 35 秒 | 青色接收微核 | 参考位置 (1370, 410)，保持缺口、受光侧和尺度 |
| 47.5 秒 | 主微核与仍可见的旧路径 | 主微核参考位置 (680, 575)，其后等待镜头保持可追踪 |
| 57.5 秒 | 沿旧路径到达的回声 | 到达点为当时主微核位置；55–58 秒相机稳定，突出运动来自回声 |
| 82.5 秒 | 开场微核的材质与缺口 | 参考位置 (960, 620)，标题区留在上方 |

这些坐标是分镜锚点，不是已经从渲染器测出的结果。最终相机构图调整时，交接两侧一起更新。连续交接的目标为同一时刻位置差不超过 1 个 1080p 逻辑像素；非停顿点的屏幕速度也需连续。停顿属于时间轴显式设计。

## 原创音乐与声音事件

音乐以 A 为音中心。开头采用 Am(add9) 的空旷感，回应段展开到 Cmaj7 的较亮和声，结尾收为 Asus2。主旋律只用 A3、E4、B4 建立可记忆的短动机；回应声部反向回答并改变音色，后半段再增加内声部。具体旋律时值在带声样片中确定。

配器由低音脉冲、软质敲击、柔和键音、持续和声、少量气息纹理组成。主微核使用偏干、偏中间的音色；青色回应初次出现时更远、更薄，返回后逐渐靠近，声像随画面位置缓慢变化。

双击是一个音乐动机：通常每两拍出现一组，两击间隔初定 0.16 秒，第二击更轻。第一击使微核收紧，第二击让边缘回弹，随后波前离开。镜头不随每一击晃动；相机使用较慢的段落包络。

| 事件 | 时间 | 声音动作 | 画面动作 |
| --- | --- | --- | --- |
| 第一次发声 | 0 秒 | 一组干燥双击，弱环境底 | 主微核两级形变，第一次显出纤维 |
| 尾迹开始有形 | 10 秒 | 三音动机进入，增加轻擦音 | 曲线具有连续受光边缘 |
| 薄膜成为传播介质 | 22.5 秒 | 延迟声部展开 | 首个完整波前出发 |
| 第二种节律出现 | 35 秒 | 青色声部错开 0.3125 秒 | 远端用不同相位回应，波前暂不重合 |
| 撤去密度 | 47.5 秒 | 按层撤鼓、键音与持续音 | 外围受光收回，保留旧路径 |
| 等待窗口 | 55–56.875 秒 | 不触发新的双击，先前尾音逐渐耗尽 | 相机保持，微核仍可见 |
| 远端先声 | 56.875 秒 | 一个很轻的远端短音 | 青色亮点沿旧路径开始回程 |
| 回声到达 | 57.5 秒 | 主拍重新落下，原动机得到回答 | 只在到达处触发形变，再向外传播 |
| 关系展开 | 65–72.5 秒 | 七个新节点各自获得一次轻音，避开持续密集重音 | 共九节点依次被唤起 |
| 高潮揭示 | 72.5 秒 | 最完整和声、较宽声像 | 视点抬升，显出统一起伏表面 |
| 标题进入 | 82.5–85 秒 | 双击逐渐成为主要声音 | 让出留白，先“心”后“跳”，85 秒完全可读 |
| 最后一组双击 | 88.75 秒 | 第二击在 88.91 秒，尾音收至 90 秒 | 局部轻弹，远端保留微弱回应 |

音频以 48 kHz 制作，主事件以样本位置保存；视觉从同一事件表读取秒值，按最近视频帧呈现，30 fps 下单次量化误差目标不超过 16.7 ms，不累积时钟误差。恒速设定下拍网格可以精确生成；若使用实录、变速或外部歌曲，必须以实际音轨重新校准。

计划交付独立的脉冲、旋律、氛围和效果分轨及立体声混音。混音目标暂定约 -16 LUFS、真峰值不高于 -1 dBTP，以保留停顿与高潮的落差；最终值在试听和编码后测量决定。

## 制作架构

一个主时间轴同时驱动场景、相机、材料、排字和声音事件。建立以下职责边界即可，不将三个仓库整体拼接为一套工程。

| 模块 | 职责 |
| --- | --- |
| timeline | 90 秒段落、十八个镜头段、节拍和命名事件 |
| geometry | 微核、持久曲线、薄膜与九节点的时间状态 |
| camera | 视点、焦点和速度曲线；输出统一投影 |
| layers | 暗底、远层、薄膜、波前、前景折边与标题 |
| sound | 原创声音与分轨编排；导出与画面共用的事件数据 |
| render | 指定任意时间绘制一帧，离线渲染并完成音画合成 |
| review | 镜头中点、交接邻帧、音画命中点和最终文件检查 |

几何和状态以绝对时间、固定种子求值，不用上一帧的位置逐帧累加。传播采用确定性的事件包络与沿曲线距离函数；薄膜形变采用可复算的波形叠加。这样即使乱序抽帧，也能得到同一时刻应有的画面。

WebGL2 负责薄膜表面、曲线、遮挡和亮部；Canvas 负责清晰标题。先合成场景与前景，再做受控的辉光与调色；阅读文字保留独立清晰层。只有少量用于表现空间的标题遮挡由显式遮罩控制。

离线渲染固定使用 t = n / 30，n 为 0 至 2699。资源和本地字体全部就绪后才采样；使用 PNG 或原始像素传入 FFmpeg，明确 RGB 到 BT.709 的转换和色彩标记。运动模糊按需要加入，但硬切和命名冲击事件不跨边界混样。

音画完成后输出高质量主文件与 H.264/AAC MP4 分享版，并核对帧数、时长、声音存在及尾帧。实时预览不能代替离线输出的验收。

## 素材与预期交付

主体几何、颜色和声音均为本片原创。需要的资源是微核材质、可平铺薄膜纤维、局部粗糙度、两种脉动音色、三个主旋律音、氛围与授权字体。资源通过清单记录来源、用途和许可。若生成纹理，应以无文字、可平铺、可拆分表面通道为目标，再进入统一材质系统。

全片制作阶段的预期交付如下，本轮只交付设计与研究材料：

- 可定位到任意时间并播放的本地预览。
- 可修改的源码、timeline、事件表、材质和依赖说明。
- 原创音频分轨与无损立体声混音。
- 1080p30 的 90 秒主文件及 MP4 分享版。
- 分镜检查图、关键交接检查结果和最终媒体参数记录。

本轮的机器可读分镜表位于 docs/heartbeat/heartbeat-timeline.json，它是设计数据，不是已完成的渲染工程。

## 分阶段验收

优先制作两个带声样片窗口：17.5–22.5 秒检验曲线到薄膜的连续性，55–65 秒检验等待、回声移动与到达。总计 15 秒，分别保留原时间码，在评审时并列观看，不拼成假的完整叙事。
