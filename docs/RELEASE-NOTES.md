# 心跳 v16 · 原成片与完整制作媒体档案

161.7 秒，30 fps，4K 与 1080p；无旁白的原创图形音乐短片。

- 两个 MP4 是原始完成的成片，未在开源整理时重剪。
- `runtime-v16.zip` 包含当前版本运行所需的媒体对象；用仓库 `tools/restore-media.py` 校验并还原。
- `production-media-*.zip` 保存其他现存制作阶段的视频、样片、关键帧、音频分轨和素材，按内容去重存储。用 `--history --edition heartbeat-film-vXX` 或 `--all` 还原。
- 完整清单、原始路径、字节数和 SHA-256 在仓库 `media-manifest.json`、`release-assets.json`。
- 实际对话、制作指令、源码快照、封面及制作说明在仓库中。

仅下载某个媒体对象包不会自动得到可运行目录；请使用还原脚本。完整媒体档案体积较大，建议先从当前运行素材和局部渲染开始。
