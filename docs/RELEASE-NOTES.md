# 心跳 v16 · 最终成片与制作工程

161.7 秒，30 fps，4K 与 1080p；无旁白的原创图形音乐短片。

- `heartbeat-v16-1080p.mp4` / `heartbeat-v16-4k.mp4`：原始最终成片，未在开源整理时重剪。
- `runtime-v16.zip`：最终工程所需字体、心电数据、钢琴采样、混音和分轨，用仓库 `tools/restore-media.py` 校验并还原。
- `selected-iterations.zip`：少量原始样片与截图，可直接解压；时间位置与学习入口见 `docs/ITERATIONS.md`。
- 完整源码、原创设计与分镜、制作记录、提示词、封面和许可说明位于仓库；保留历史文本源码供比较。

本次精简为最终版工程、制作过程和精选案例。全部旧版完整视频与重复媒体留在本地，不包含在 Release 中。当前源码可独立重绘全片；原成片曾保留旧版画面并替换局部，重绘不承诺与原导出逐像素一致。

文件大小与 SHA-256 见 `release-assets.json`，运行和修改方法见 `docs/REPRODUCE.md`。
