# 公开范围与真实边界

本次采用“最终版完整工程＋制作过程说明＋精选迭代案例”。本地旧版、原始视频和素材均保留；GitHub 不上传所有旧版完整视频、重复截图及中间音频。

根目录是 v16 可编辑工程，Releases 提供最终 1080p、4K 成片，当前运行素材包和精选迭代包。源码、原创设计稿、分镜、实际制作记录与封面在仓库内。已经整理的第一版至 v16 文本源码快照保留于 history/，供比较实现；它们不意味着对应的全部历史媒体也已公开。公开 Git 提交从此次整理开始，不伪造过去日期或提交历史。

`media-manifest.json` 只列本次实际发布的媒体；`release-assets.json` 记录下载包大小与 SHA-256。运行包按内容去重，须用还原脚本恢复；精选迭代包可直接解压播放。`process/archive-coverage.json` 中原始库存统计与当前公开统计分开标明。历史源码中的旧路径、链接与日志记录仅说明当时状态。

公开对话包括本片制作阶段可用的用户消息和助手公开回复，工具输入另存 JSONL。按作者指定范围排除参考学习资料、其他项目及私人信息；必要的第三方许可仍保留。没有公开模型隐藏推理、系统／开发者指令或原始完整会话文件，也没有声称恢复所有子任务会话或未保存的尝试。

历史反馈与阶段性评价可能冲突，最终作品以 v16 原成片为准。AI 参与代码、声音合成与封面制作，封面提示词随文件提供；提示词不保证逐像素再生成相同图片。

复现条件和局限见 REPRODUCE.md，技术检查见 VERIFICATION.md。没有把短片段渲染成功说成全片正常速度审片或试听通过。
