# 归档范围与真实边界

本项目公开《心跳》现有制作记录。第一版至 v16 的现存源码快照在 history/；不是伪造过去日期或提交历史。公开 Git 提交从本次整理开始。

媒体按 SHA-256 去重保存于 Releases 的多个 ZIP。`media-manifest.json` 将每个原始路径映射到内容对象，同一文件在多个版本中出现时只存一份。视频、音频、关键帧、分镜和封面保持原有字节；文本统一为 UTF-8，并清理作者机器路径及私人信息。

完整视频提供直接下载，其他中间媒体通过脚本按清单还原。旧的大型工程 ZIP 不重复上传，其展开后的源文件和媒体已按本清单收录。临时缓存、第三方软件运行时和未完成编码文件不属于公开成片。

公开对话包括本片制作阶段可用的用户消息和助手公开回复；工具指令另存 JSONL。为遵守作者指定范围，部分非公开段落有省略标记。没有公开模型隐藏推理、系统／开发者指令、其他项目内容或原始工具输出中的私人数据。没有声称已恢复所有子任务的独立会话或所有未保存的尝试。

历史反馈可能与最终方向冲突，也可能含阶段性判断。最终版本以 README 和原始 v16 成片为准。保留这些记录是为了展示真实修改过程，不把中途的自评当成最终质量证明。

字体、采样、数据、第三方源文件按各自许可保留署名。AI 参与代码、声音合成与封面制作；实际可用的封面提示词一并提供。AI 图像生成不承诺通过同一提示词逐像素重现，已生成的封面文件本身随项目提供。

技术复现检查另见 VERIFICATION.md。用户是最终艺术审片者；不把短片段渲染成功说成完整正常速度审片或试听通过。
