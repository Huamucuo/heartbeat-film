# 精选迭代案例

这些是制作时实际保存的片段与截图，没有为开源重新制作历史演示。下载 [selected-iterations.zip](https://github.com/Huamucuo/heartbeat-film/releases/download/v16.0.0/selected-iterations.zip) 后可直接解压播放。文件夹保留原版号和文件名。

| 案例 | 包内文件 | 对照方式 |
|---|---|---|
| v05 局部修订 | `heartbeat-film-v05/output/heartbeat-v05-revision-preview.mp4`，46.5 秒，对应当时全片 37.5–84 秒；另附 74 秒原截图 | 结合 v05 的 README、迷宫与日期组件，以及过程对话理解早期方案；不把早期时间套用到最终版 |
| v11 尾声试片 | `heartbeat-film-v11/output/heartbeat-v11-ending-final-trial.mp4`，16 秒，对应当时全片 171–187 秒；另附 176.5 秒原截图 | 对照最终成片末段，以及 v11/v16 的尾声源码，观察尾声改动与保留部分 |
| v16 最后一次局部替换 | `heartbeat-film-v16/output/heartbeat-v16-ecg-flash-4k.mp4`，3 秒，对应最终成片 93–96 秒 | 对照最终成片同一时刻、`measured-ecg.mjs` 和 `maze-breath.mjs`，研究黑场、实测波形、亮芯和拖影 |

完整最终片在同一 Release 中。精选包不是全部历史媒体；历史源码快照中的某些旧视频链接与检查截图不包含在本次发布内。历史文件保持当时的叙述，以此页和根目录说明为当前公开范围。
