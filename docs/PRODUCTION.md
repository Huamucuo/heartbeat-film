# 制作流程与学习路线

本文是根据现存源码、制作记录和用户反馈整理的导览。真实对话与版本保存在 process/ 和 history/，不把整理时补写的说明冒充当时的提示词。

## 主题如何进入画面

主题是活着的意义，情绪偏悲观。心搏从个体进入重复的时间和日常，路线加速、回归，随后转入具体生活。结尾由日常线条汇成代码心脏，城市窗灯逐户熄灭，心搏由有力变弱，最终留下模拟监护长鸣。

制作过程中，用户不断纠正过空、过于重复、塑料感、含义不清的文字与图案，以及音乐过急和衔接生硬。由此形成了实际的多轮迭代，而非预先设计好后一次生成。

## 重要变化

- 早期尝试抽象实体与图形，后续改用更克制的深色图形与连续线条。
- 心搏由循环同一形状改为逐拍差异；日期随时间推进。
- 生活段加入电话等可辨认物件与时代变化；后来改为九个生活模块同时演变，再转向非建模的刻绘表达。
- 迷宫先尝试三维与跟随视角，最终采用满屏溢出的固定平面、实体墙体、多彩路线和不断加速的数字翻页。
- 迷宫路线被要求分散、增加数量并加速；取消在迷宫中刻意组成心电图的方案。
- 尾声取消片名与整体淡出，改为线条聚成心脏、窗灯逐户暗下、字符变化、局部故障、停搏与长鸣。
- v13 修整音乐衔接与模块演变；v14 压缩迷宫时间；v15 改为较早拉远、模糊、黑场及一次实测红色心电；v16 将扫线收紧至约 0.4 秒，加入亮芯与拖影。

具体修改发生在哪个阶段，以各目录内的历史 README、场景源码及对话为准。历史文件中的时间与要求不能直接套在最新版上。

## 从组件到影片

1. 从 `src/pacing.mjs` 开始理解播放时间与创作时间的映射。v16 为 161.7 秒，一些对象仍使用更长版本的创作时钟。
2. 看 `src/film.mjs` 的逐帧组合：背景、场景、曝光累积、泛光、文字、故障。字体在采样累积之后绘制，防止重复字形。
3. 迷宫看 `code-maze.mjs`、`code-direction.mjs`；生活看 `code-lives.mjs`、`code-life-programs.mjs`；尾声看 `code-ending.mjs`。
4. 单次心电的形状与扫线见 `measured-ecg.mjs`、`maze-breath.mjs`；实测数据的截取方法在 `tools/prepare-measured-ecg.py`。
5. 声音事件在 `audio/score.json`；合成在 `audio/synthesize.py`；独立分轨用于理解配器与变化。
6. `tools/render.mjs` 用浏览器在明确时间绘制 PNG 帧，再交给 FFmpeg 编码；保持帧顺序与共同时间基准。

## 声音与最终拼接

钢琴使用公开授权的 Salamander 采样；其余声音按事件进行合成。后期为保留已经认可的区间，使用了旧版 PCM 与旧版画面，再替换局部。因而“最新版源码全片重绘”与“当时最终成片的拼接还原”是两条清楚区分的路径。

v16 仅重新绘制 93–96 秒，其他画面取自 v15 已导出的 4K 文件。新的开源入口补足便携运行与素材还原，不修改原成片的艺术内容。

## 如何试着改一个镜头

先还原运行素材，修改对应组件，渲染几秒局部，观察完整运动；确认时间映射与声音事件后再扩展到全片。不要把历史脚本全部执行一遍：很多脚本是某次修补的入口，会覆盖生成文件或依赖前一版输出。请先读 REPRODUCE.md。
